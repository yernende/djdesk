# Product Ideas

## Focused Sector View

Add a second circle-display mode for detailed planning on small screens and dense
key areas.

Instead of showing the whole circle, the view would show the active sector, its
two neighboring sectors, and the two boundaries between them. This should make
the areas that matter for the next transition much larger and easier to tap,
especially on phones.

Open questions:

- Whether this mode should open on tap, via a segmented control, or both.
- Whether boundary modal-mixture zones should appear as full columns between
  sectors in this focused view.
- Whether the draft set should automatically move the focused view to the last
  added track's section.
